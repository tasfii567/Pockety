# Pocket Pop 🐷 — free money tracker (Next.js + Vercel, no database)

Your data is saved in your browser on the device you use.

## Deploy (free)
1. Push this folder to GitHub.
2. On vercel.com: Add New -> Project -> import the repo -> Deploy.
3. Optional: add env var NEXT_PUBLIC_CURRENCY (e.g. ৳) and redeploy.
4. On your phone: browser menu -> Add to Home Screen.
